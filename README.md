# Mê Truyện Chữ – Spring Boot Backend

RESTful API backend for the *Mê Truyện Chữ* Android application, built with **Spring Boot**, **Oracle Database**, **Spring Security (JWT)**, and **Google Gemini API**.

## Setup & Configuration
1. Copy `src/main/resources/application-example.properties` to `src/main/resources/application.properties`.
2. Update your Oracle Database credentials, JWT secret key, and `GEMINI_API_KEY`.
3. Run the Spring Boot application (default port: `9999`).
